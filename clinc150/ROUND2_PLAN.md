# 第二轮：进一步提高 CLINC150 准确率

第一轮测试结果已经公开；本轮是知晓既有汇总结果后的后续开发，不是全新盲测。
只分析训练/验证样本；不读取第一轮测试错误来设计方法。固定候选后一次性测试，
并如实报告所有被选方法，包括失败结果。不得将验证分数写成测试分数。

## 有界候选与选择

1. 对既有六个模型做验证错误重叠分析。固定比较三种概率均值集成：CE 三种子、
   SupCon 三种子、全部六模型。集成必须明确额外推理成本。
2. 权重平均：逐种子 CE/SupCon 各半；跨种子 SupCon 平均；全部六模型平均。
   不增加模型大小，但不同随机分类头可能使平均失败；负结果必须保留。
3. 从原始 Laya 初始化训练两个候选，先固定 seed=13：
   - balanced_supcon：每批 16 个同类四样本块（最多 16 类），每轮每个样本恰好一次，保证每个锚点有正样本，
     CE + 0.1 SupCon；8 epochs，lr=2e-5，其他设置与第一轮一致。
   - rdrop：CE + 0.1 SupCon + 1.0 对称 KL；编码器 embedding/attention/MLP dropout=0.1，
     两次独立前向的 CE/SupCon 取平均；8 epochs，lr=2e-5。
   初始计划先筛选 seed 13 再扩展。执行期间 GPU 0 的其他任务结束，
   因成组训练 seed 13 仅提高一个验证样本，单次筛选不可靠：在 R-Drop seed 13
   尚未完成、未读取本轮测试前，将两个候选都扩展 seed=42/87，完整报告两家族。
   这次预算扩展基于资源释放及随机性控制，不基于测试结果。
4. 所有完成的单模型和上述固定平均模型按 validation accuracy、NLL 选发布单模型。
   同时允许发布验证最优的固定集成；不把集成提升说成单模型提升。
   三种子复验期间、测试前，补充两个新家族各自的三种子等权概率集成，
   共五个固定集成候选；不搜索任意子集或额外混合系数。
5. 最终冻结路径、权重摘要、推理规则后，统一测试本轮入选方法。
   与第一轮进行逐样本配对统计，但不利用配对错误再次修改本轮方法。

训练只使用 15000 train；选择仅使用 3000 validation；测试为原始 4500 in-domain。
若继续迭代导致验证集被过度使用，应在另一数据集/新标注集检验推广性。

已有方法来源：SupCon https://arxiv.org/abs/2004.11362 ，
R-Drop https://arxiv.org/abs/2106.14448 ，
Model soups https://arxiv.org/abs/2203.05482 。这些方法不声称本项目首创。

资源变更：R-Drop seed 42 在共享 GPU 0 上启动后耗时接近翻倍，保留其未完成运行与日志，
在 GPU 1 空闲后按完全相同 seed/config 从原始权重重启；该中断运行不参与模型选择。
