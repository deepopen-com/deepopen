# 第四轮：候选意图联合判别

目标为 CLINC150 full、150 类闭集测试准确率超过 98%，不是预先保证的结果。
已知前三轮测试汇总，属于后续开发。只读取 train/val 开发，冻结后统一测试。
保持 15000/3000/4500 原划分，不添加外部生成数据，不调整测试标签。

## 新结构

固定第二轮验证选中的 rdrop_42 为召回器，取 top-5 意图。
使用原始 Laya DecisionModel 的 encoder、typed head 和候选 marker scorer，
联合编码句子与五个候选意图，微调 listwise CE。候选顺序训练时随机置换。
它是二阶段系统，报告两模型存储和推理开销，不称作单编码器改进。

两条先导路线均 seed 42、6 epochs、encoder LR 1e-5、head LR 5e-5、
batch 16、累积 4 步、AdamW weight decay .01、10% warmup、线性衰减、
梯度裁剪 1、BF16。初始化完整原始 Laya 权重，保留原始 dropout。
只训练选择题 CE，冻结无关 act_head；候选温度由验证选择。

1. label：候选仅使用标签名称，将下划线替换为空格；最大序列长度 128。
2. example：每个候选另外给出一条来自训练集的近邻示例；最大长度 256。
   特征由固定召回器生成。对训练查询排除自身和规范化文本相同的示例。
   验证/测试的记忆库始终仅含训练集。

训练 top-5 中缺失金标时，用金标替换最后一项，仅用于训练；验证和测试绝不注入金标。
训练示例相似度使用固定召回器，只用于训练数据中的困难候选和示例选择。
先导完成后按验证 accuracy/NLL 选择路线，补训 seeds 13/87。
验证选择混合概率：(1-alpha)*召回器概率 + alpha*重排器稀疏概率，
alpha={0,.25,.5,.75,1}，重排器温度={.5,1,2}。同时保留纯重排器结果。
不搜索任意种子子集。候选为所有完成运行和选中家族固定三种子等权集成。

## 验证阶段扩展：候选顺序一致性

首两个先导尚在训练、没有本轮测试结果时，增加 `label_consistency` 先导 seed 42。
沿用 label 输入和训练超参数，每条样本独立产生两次候选随机排列和 dropout 前向，
将两次 logits 按意图 ID 对齐后加入系数 1 的对称 KL，CE 取两次均值。
编码器 dropout 设为 .1。候选重排和 R-Drop 一起变化，不能独立归因。
该分支每更新有两次前向，训练成本高于普通 CE。先导选择扩展到三条路线，
胜出路线仍补训 seeds 13/87；测试前记录全部选择。现有两个先导不重跑。

另在 label_42 完成后只对其已选 checkpoint 做了一次验证集算术/几何概率融合检查，
几何融合没有超过原算术融合。保留 `fusion_probe.json`，不改变主选模或推理规则。

## 验证与证据

先报告验证 top-5 recall、截断情况和错误类型，不读取测试错误设计方法。
保存最优 epoch、完整训练曲线、验证搜索表、数据/代码/权重 SHA256。
测试前冻结最终选择，统一测试家族三个种子和验证选出的集成；所有负结果保留。
若达不到 98%，如实报告，不能通过事后选择测试最优种子声称达标。
该方法与原始专用分类头不同；预训练原生 head 复用和二阶段结构均需明确说明。
