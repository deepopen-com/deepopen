# Laya 的 CLINC150 专用适配与对照实验

状态：三种子训练、冻结对照、消融及测试评估已完成；正式榜单提交尚未完成。

## 实测结论

在相同初始化来源、数据、更新步数和超参数下，加入监督对比损失的分类头结果
从普通微调的 **97.015% ± 0.100 pp** 提升至 **97.326% ± 0.046 pp**。
均值提升 **0.311 个百分点**，相对错误率降低约 **10.42%**。标准差来自三个种子，
测试集为完整 4500 个 in-scope 样本。这里的比较没有使用原型或近邻融合。

| 种子 | 普通 CE 微调 | CE + SupCon | 差值 |
|---|---:|---:|---:|
| 13 | 96.911% | 97.311% | +0.400 pp |
| 42 | 97.111% | 97.289% | +0.178 pp |
| 87 | 97.022% | 97.378% | +0.356 pp |

SupCon 的平均 macro-F1 为 0.97317，对照为 0.97009；平均 NLL 从 0.13868 降至
0.13257。原始分类头 ECE 则略有变差（0.01308 → 0.01353），不能称所有指标都改善。
完整结果与负结果见 [RESULTS.md](RESULTS.md)，曲线见 artifacts/figures/controlled_comparison.svg。

将同一测试样本在三个种子中的差值作为一个簇共同重采样，平均准确率差的
95% bootstrap 区间为 **[+0.111, +0.519] pp**。该区间以这三对训练结果为条件，
不能代表所有可能训练种子。分种子的 McNemar p 值为 0.030、0.382、0.048
（未做多重比较校正），种子 42 的配对区间跨零；不应宣称每次运行均统计显著。

原型及近邻融合没有稳定提高测试准确率：CE 近邻融合为 97.030%，SupCon 近邻融合
为 97.230%。这些消融与不利结果全部保留，没有据此再修改训练参数或重复调测试集。

## 模型交付

监督对比模型族内按分类头验证准确率、再按 NLL 选择种子 87；其测试准确率为
**97.378%**，macro-F1 为 0.97365。单模型有 **394,935,446** 个参数。
服务器模型目录为 `/opt/laya-clinc150/artifacts/improved_model`，推理接口是固定 150 类分类。

完整权重比对确认 encoder 参数发生实际更新，相对 L2 变化约 0.00820；原始与训练后
checkpoint 的 SHA256 不同，见 artifacts/weight_verification.json。
导出的模型已通过余额查询与机票预订输入的加载及推理检查。

独立的 L20 GPU 1 上，batch 1、padding 64、20 次 warmup 后测 100 次，
热启动 forward + softmax 的 p50 为 **9.917 ms**，p95 为 **9.977 ms**。
这些时间不含分词、权重加载和网络，不是与原始 Laya 在相同条件下的速度对比。

另保留全局验证搜索选出的融合候选 `artifacts/release`（CE 种子 87），
其测试准确率为 97.089%。该候选与 SupCon 模型族的研究导出分别保留来源与选择规则。

## 问题

Laya 将问题、候选标签和用户文本拼接进同一编码序列。在所审计的 150 类
CLINC150 问题中，默认 512 token 配置只保留 126 个候选标记，无法完整表达任务。
因此不能将该配置下的输出直接用作完整 150 类准确率基线。

本实验将 Laya 的编码器用于固定标签的专用分类模型，避免候选标签与文本竞争
序列预算。这个改动牺牲了原有任意 typed-decision 接口，因此研究结论限定为
CLINC150 意图分类，不能推广为 Laya 的全部功能均得到增强。

## 方法

输入文本经 Laya 编码器得到 token 表示，对非 padding 位置做平均池化，得到表示 h。
线性分类头使用 softmax(W h+b) 输出 150 类概率。

对照模型仅最小化交叉熵。实验模型在完全相同的初始化、batch 顺序、学习率和
更新步数下，加入权重 0.1 的监督对比损失；表示归一化，温度固定为 0.1。
同一 batch 中同类样本为正对，不同类样本为负对，排除自身；没有正对的 anchor
不参与对比项。这里没有额外数据增强、教师模型或测试数据训练。

具体目标为 `L = CE + 0.1 × SupCon`。对每个有正样本的 anchor i，SupCon 对其
同类样本 j 平均计算 `−log[exp(z_i·z_j/0.1) / Σ_{k≠i} exp(z_i·z_k/0.1)]`，
再对有效 anchor 平均。z 是池化表示的 L2 归一化，不另设投影网络。

另设冻结编码器对照：原始 Laya 编码器固定，使用相同线性头初始化、8 epochs、
batch 64、head LR 2e-4、warmup、weight decay 和三个种子，仅更新分类头。
编码器表示预先缓存以节省重复计算。该对照量化编码器微调的贡献，不等价于
原始 typed-decision API 的零样本结果。
这是固定训练步数与超参数的冻结对照，不是经过独立充分调参的最优线性探针；
不能用它的差距夸大额外算法创新。

另外对两个模型都使用训练集表示构建各类别的归一化均值原型。
余弦相似度经温度 softmax 得到原型概率，与分类头概率线性混合。
两个模型使用同一个验证搜索网格，分别报告分类头结果与混合结果。
这样可以区分训练损失的贡献与推理融合的贡献。

在首次测试前，因验证种子间的对比损失收益不一致，另加入训练集近邻记忆对照。
记忆库保存 15000 条训练样本的归一化表示；余弦近邻经过 softmax 加权投票，
与已选分类器/原型概率混合。所有方法使用同样的 k∈{1,4,8,16,32}、
温度∈{0.02,0.05,0.1}、混合权重∈{0,0.1,0.25,0.5,0.75,1} 验证网格。
这一扩展不更新编码器权重，结果须归为检索增强的系统改进，不能冒充训练目标的收益。
方法选择发生于验证阶段；最终测试用于一次性检查泛化。

监督对比学习和类原型已有先前研究，本项目不将这些基础方法声称为原创：

- Khosla et al., [Supervised Contrastive Learning](https://arxiv.org/abs/2004.11362)。
- Snell et al., [Prototypical Networks for Few-shot Learning](https://arxiv.org/abs/1703.05175)。

本项目的可报告内容是 Laya 在完整多类别任务上的适配、受控消融与可靠性测量。
是否具有足够的论文创新性，需要结合结果和进一步文献评审判断。

## 数据与泄漏检查

使用作者发布的 data_full.json，固定 commit 及文件 SHA256。
主评测为 150 类闭集任务，训练 15000、验证 3000、测试 4500。
OOS 样本不参与此主任务，不将闭集准确率作为 OOS 检测效果。

对去除首尾空格并转小写后的文本检查发现：train/val 重复 3 个，train/test
重复 2 个，val/test 无重复。保留官方划分以方便比较，并另外报告排除与训练
文本重复的测试样本后的指标。该检查不能保证不存在语义重复。

训练和验证集最长分别为 39、30 token，最大长度 64 不截断这些输入。
Laya 上游权重的完整训练语料不可核实，所以不能声称基础权重从未接触 CLINC150。

## 预先固定的训练与选择规则

- 三个随机种子：13、42、87。
- 8 epochs；batch 64；最大长度 64。
- AdamW，encoder LR 2e-5，分类头 LR 2e-4，weight decay 0.01。
- 10% warmup 后线性衰减；梯度范数裁剪 1.0；BF16 autocast。
- 检查点按验证 Accuracy 选择，平局时按验证 NLL 选择。
- 原型仅由训练集构建；混合与温度仅用验证集选择。
- 在首次测试评估前，对两种方法都用验证 NLL 拟合最终混合概率的单一温度。
  正温度不改变 argmax，保留原始结果，并另外报告校准结果。
- 固定所有方法后单独评测测试集，不依据测试错误反复修改模型。
