# Laya 最大间隔分类头验证对照

固定原 Laya rdrop_42 的归一化句子特征，只用训练集拟合 LinearSVC/RBF SVC；完整协议见 MARGIN_PLAN.md。

最佳验证准确率 **98.4000%**，候选 `linear_1.0`，分类头权重 0.25，温度 0.25。
没有超过原 Laya 的 98.4%，按预定规则不进入测试，不发布新的推荐模型。

| 分类器 | 该候选验证最优准确率 |
|---|---:|
| linear_0.01 | 98.4000% |
| linear_0.1 | 98.4000% |
| linear_1.0 | 98.4000% |
| linear_10.0 | 98.4000% |
| rbf_1.0_1.0 | 98.4000% |
| rbf_1.0_10.0 | 98.4000% |
| rbf_10.0_1.0 | 98.4000% |
| rbf_10.0_10.0 | 98.4000% |

所有候选都允许混合权重为零，因此该表包含退回原模型的配置，不能把相同的 98.4% 当作新分类头单独达到的成绩。
串行尝试在完整搜索结束前停止并归档，后续四个 CPU worker 求解相同候选；没有停止其他项目的进程。
scikit-learn 对混合后 float64 数组发出行和容差警告。复核确认行和最大误差小于 1e-6，逐行归一化没有改变任何候选预测，最高验证准确率也没有改变。
该实验是负结果，只有一个固定编码器种子，不支持跨种子稳定改进结论。
