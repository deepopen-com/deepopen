# 第二轮方法细节与可支持的研究结论

## 固定骨干与基本分类器

沿用第一轮的 Laya ModernBERT 编码器初始化、掩码均值池化和 150 类线性头。
所有新训练都从原始 Laya 编码器初始化，不在上一轮测试选中的模型上继续拟合。
相同 seed 使用相同分类头初始化。最大序列长度 64，batch size 64，训练 8 epochs。
AdamW：encoder LR 2e-5、head LR 2e-4、weight decay 0.01；10% warmup 后线性衰减。
梯度裁剪阈值 1；BF16 autocast；验证准确率优先、验证 NLL 次优选择 checkpoint。

## 成组监督对比学习

第一轮随机 batch 在 150 类上每个样本有同类正样本的概率约为
`1 - (149 / 150)^63 = 34.39%`（独立均匀采样近似）。无正样本的锚点不会产生 SupCon 损失。

新采样器将每类 100 个训练样本随机分为 25 个四样本块。
每个轮次中对 150 类的顺序进行 25 次随机排列，将块依次合并为 batch。
每批 16 个块，最后一批 6 个块。跨排列边界时某类可能出现两个块，
因此每批是**最多** 16 类，而非保证恰好 16 个不同类。
每轮恰好 235 个 batch，15000 个样本各出现一次，所有锚点至少有三个同类正样本。

损失为 `CE + 0.1 * SupCon`，对比温度 0.1。保持其余超参数不变。
损失绝对值不能直接与原随机采样比较，因为正样本数量改变了 SupCon 的数值尺度。

## R-Drop 与监督对比学习

第一轮编码器的 embedding、attention、MLP dropout 均为 0；分类头 dropout 为 0.1。
新候选把编码器中的这些 dropout 设置为 0.1，并启用 attention 输出的 dropout。
分类头 dropout 仍为 0.1。

对同一个 batch 做两次独立随机前向，得到概率分布 `p1, p2` 和归一化特征 `z1, z2`：

```text
L = [CE(p1,y) + CE(p2,y)] / 2
  + 0.1 * [SupCon(z1,y) + SupCon(z2,y)] / 2
  + [KL(p1 || p2) + KL(p2 || p1)] / 2
```

KL 对类别求和、对 batch 求平均；两侧分布都参与梯度计算。
SupCon 在各自的 batch 内计算，没有将两次前向当作额外同类样本拼接。
随机 batch 的样本顺序策略与第一轮一致。

该候选一次更新需要两次前向，训练计算量增加。推理仍然一次前向，
dropout 在 `eval()` 中关闭，没有增加可训练参数。

本轮验证的是“编码器 dropout + 一致性正则 + SupCon”这个组合，
未单独比较“只开启编码器 dropout”和“只加入 KL”，因此不能将所有变化归因于 KL。

## 权重平均与概率集成

权重平均把指定模型各参数的等权算术平均保存为一个完整 checkpoint。
其推理架构和参数数量与单个模型一致。不同 seed 的分类头初始化不同，
直接平均可能损伤语义对齐，因此是否有效由验证结果决定，不能由公式保证。

概率集成对多个模型各自的 softmax 概率取等权均值。
本轮指定 CE 三模型、SupCon 三模型、全部六模型，以及两个新训练家族各自的三种子集成，
只根据验证 accuracy / NLL 选择。集成需要多个编码器前向，必须单独报告成本。

## 证据与局限

- 两个新训练候选各保留 seeds 13、42、87 的结果，报告均值与样本标准差。
- 新一轮开发已经知晓第一轮测试汇总分数；本轮结果不是新的独立盲测。
- 在本轮方法与权重冻结后才运行测试，不分析测试错误再修改本轮方法。
- 配对 bootstrap 以测试样本为重采样单位；三种子联合区间条件于这三个已训练模型，
  不能解释为涵盖所有可能训练随机性的区间。
- McNemar p 值为未做多重比较校正的结果，应配合效应量和区间解读。
- 单数据集上的提升不足以证明跨领域推广性或论文方法创新性。
